2025 年终盘点：三次"降维"，一次范式转移

如果只能用一句话记住 2025，我不会说 GPT-5，也不会说 Gemini 3。我会说：这一年，AI 第一次真正"变便宜"了——推理成本降了一个数量级，而这，比任何旗舰发布都更改变游戏规则。

旗舰模型是烟花，好看，但烧完就没了。真正留下来的，是三次"降维"：推理变便宜了，连接变标准了，机器开始"看"着思考了。

一、从"更大"到"更巧"：推理的 commodity 化

转折点是年初的 DeepSeek R1：开源推理模型，用 GRPO 训练，成本只有 OpenAI 同级的零头，效果掰手腕不落下风。R1 的冲击不是"又一个强模型"，而是把"推理"从奢侈品变成了 commodity——测试时计算这条路，不需要千亿预算也能走。

还有个被低估的细节：o1 是第一个按"思考 token"收费的模型——"想"第一次有了明码标价。账单里出现"思考税"：答案 200 token，内部思考 2000 token，全按输出单价收费。这个定价直接催生了后来一整套成本方法论：按难度路由、思考预算、快慢搭配。定价方式，塑造了工程范式。

下半年"更巧"全面接管：蒸馏的胜利（Haiku 4.5 继承旗舰九成日常能力，价格零头）；MoE 的经济学（Kimi K2 万亿 MoE，参数竞赛变成"激活参数"竞赛）；自适应推理（GPT-5.1 把"想多久"从手动挡变自动挡）。从"大力出奇迹"到"四两拨千斤"——2025 年最深层的范式转移。

二、从"模型"到"系统"：基础设施的年份

今年静悄悄的革命：单点能力的光环，让位给了系统能力。标志是 MCP 生态爆发——Anthropic 的开放标准统一了 AI 和工具的连接。在此之前，每个 Agent 框架为每个工具写一遍适配器。MCP 相当于给 AI 世界修了"集装箱标准"：模型管推理，工具管接口，中间统一协议对接。连接成本从"天"降到"分钟"，工具生态才有了爆发的可能。

围绕"系统"的一系列进展：一体化路由（GPT-5 收敛成"一个入口"，把分级路由产品化）；Computer Use（Sonnet 4.5 让 Agent 操作电脑，"手"从 API 扩展到整个操作系统）；Agent Skills（把"怎么做事"沉淀成可复用技能包）。

回头看，2025 年 Agent 进展里模型本身的贡献可能不到一半，另一半来自连接、路由、工具生态这些"脏活累活"。技术史的规律：平台革命早期拼单点突破，后期拼的都是基础设施。

三、从"闭源"到"开源"：护城河的迁移

年初 R1，年中 K2，年底 gpt-oss——OpenAI 时隔多年重开权重。2025 年开源走完：从追赶者，变成并跑者。

开源的竞争力不在"榜单第一"，在三个闭源给不了的东西：可私有化部署（金融医疗政务的入场券）；可魔改（微调蒸馏量化的前提）；便宜（高频场景的生死线）。

更深一层：开源正在重塑"护城河"的定义。当模型能力变成 commodity，护城河从"模型本身"迁移到数据、场景、工程能力。R1 开源那天，最该紧张的不是 OpenAI，是那些"套壳 API 就叫 AI 公司"的创业者。跑通的商业逻辑是 "开源模型 + 闭源服务"：权重免费，托管、微调、SLA 收费——链条上每一环都有钱赚，开源势头就不可逆。

四、评测信任危机：罗盘坏了

Q4 最值得玩味的不是任何发布，而是评测信任危机：刷榜、反刷榜、榜单污染，行业第一次集体承认用了两年的罗盘可能是坏的。

病根是 Goodhart 定律：当一个指标变成目标，它就不再是好指标。 训练集污染（评测题混进训练数据，模型是"背下来"不是"学会"）、针对性优化（全围着几个公开榜单打转）、饱和失真（头部集体 90%+，1% 差距可能是噪声）。

自救方向已出现：私有榜单（题目不公开）、动态出题（ARC-AGI 思路，每次换新题）、人工评测回归（LMArena 真人投票，贵但真实）。2026 年很可能迎来"评测体系重建"——不性感，但罗盘坏了，船开再快也是瞎开。

结语：烟花与年轮

三条主线之外，还有三件当时没上头条、后劲很大的事：React Compiler（优化从"手艺"变"基础设施"，人的脑力留给业务）；Nano Banana（对话式修图证明交互范式比参数更重要）；Prompt caching 普及（长 system prompt 从奢侈变便宜，基础设施的价格悄悄改写上层最佳实践）。

烟花负责好看，年轮负责生长。

GPT-5、Gemini 3 这些名字，五年后可能只剩 Wikipedia 上的词条；但 R1 证明的"便宜也能推理"、MCP 建立的"连接标准"、视觉推理开辟的"看想交织"，会长进每一代系统的地基里。2025 年是大模型的"青春期"：从"大力出奇迹"到"四两拨千斤"，从"单打独斗"到"系统作战"，AI 从"玩具"变成了"工具"。2026 年，看它进工厂——而进工厂的第一课恰恰是今年教的：不是最强的工具赢，是最"够用"的工具赢。
