原生多模态：翻译终究是二道贩子

过去两年，所有"会看图、会听声音"的大模型，在技术上都在干同一件事：把图片翻译成文字，再假装自己看懂了。

这不是讽刺，是字面意义上的架构描述。主流多模态模型 = 一个语言模型，外挂几个"翻译官"（视觉编码器、音频编码器），把非文本信号翻译成文本 token。而 Google 从 Gemini 一代起押注的另一条路线——原生多模态——赌的是：翻译终究是二道贩子，一起长大的孩子才是一家人。

一、拼接式：一个伟大的"翻译 hack"

图像 → ViT 编码器 → 投影层 →┐
音频 → 音频编码器 → 投影层 →┼→ 文本 token 空间 → LLM
视频 → 视频编码器 → 投影层 →┘

先说句公道话：这个 hack 极其成功。复用现成的 ViT、复用现成的 LLM，只训中间小小的投影层——2024 年所有大厂一夜之间拥有"看图"能力，工程性价比拉满。

但它有三笔"翻译税"，越到深水区越贵：

信息税：1024×1024 的图，ViT 切 patch、压向量、投影成 token，细节单向丢失。图里那行小到看不清的配料表文字，编码器觉得"不重要"就扔了——翻译官替你做了取舍，而你没机会投票。

对齐税："这张图里的猫"和"猫"这个词，来自两个完全不同的编码器，它们的"相遇"只发生在投影层之后。需要海量图文配对数据硬把两个空间拽到一起，对齐质量全看数据量和调参运气。

扩展税：每加一个新模态，就要训新编码器、调新投影层，还要担心新老模态在共享空间里打架。视频、3D 点云、传感器时序——每来一个都是新的工程战役。

二、原生：从第一层就在一起

图像 patch ─┐
音频帧 ─────┼→ 同一个 Transformer → 统一 token 流
文本 token ─┘

没有独立编码器，没有投影层。图像 patch、音频帧、文本 token，从训练第一天起就在同一个 Transformer 里一起做 next-token prediction。

常被误解的一点：原生不等于"不处理模态差异"，tokenizer 还是要的，只是薄得多——图像切 patch + 线性映射，音频按帧切分，文本正常分词。区别在于：拼接式的编码器是深度的、独立的、有自己目标函数的；原生里的 tokenizer 是薄的、联合的，唯一目标是服务主模型的预测。所有表征学习都发生在同一个 Transformer 内部。

质变是联合表征的自然对齐："猫"的图像 patch 和"猫"这个词，训练中总是一起出现、一起被预测——模型不需要"翻译"，因为它从没分开学过。就像双语家庭的孩子，不需要词典，两种语言在同一个脑子里。

跨模态推理上是降维打击："听这段音频，指出图中发出声音的物体"——拼接式做"音频→文本→图像"两次翻译，每次都丢信息；原生里音频帧和图像 patch 直接做注意力，信息零中转。

三、原生的两个地狱

这么好，为什么人人不做？两个地狱：

数据地狱：拼接式只需要"图文配对"（caption）；原生需要多模态交织数据——图文混排的网页、带字幕的视频。模型要从"自然混杂"的信号里自己学会对齐，量级和清洗难度高一个数量级。谁手里有海量视频+字幕，谁才玩得起。

训练地狱：不同模态 loss 尺度差 10 倍以上，naive 混训会出现梯度打架——模型偷懒只优化好学的模态。解法是黑艺术全套：模态采样比例、loss 权重调度、课程学习。更隐蔽的是灾难性遗忘：多模态灌多了，纯文本能力掉——得时刻盯着文本基准，防止"学会看图，忘了说话"。

真实门槛 = 数据护城河 × 训练黑艺术，缺一不可。这就是为什么它是"大厂的游戏"。

四、视频：真正的试金石

判断路线行不行的最好标尺是视频。"图像 × 时间 × 音频"的三维信号，让拼接式的三笔税同时爆炸：每帧翻译一次信息税累积；时序关系在翻译中被拍平；音画联合要做三次翻译。

原生里，视频帧和音频帧是同一个 token 流里的两种 token 类型，时序注意力天然跨模态。视频理解是去年各家发布会必秀的肌肉——它是最能拉开差距的战场，也是数据护城河最深的地方。

公平起见，拼接式有三个短期内替代不了的优势：模块化升级（换编码器不用重训 LLM，成本差两个数量级）；独立优化（站在 ViT、Whisper 这些领域 SOTA 的肩膀上）；调试可见性（管线分段，出问题知道查哪段，原生是端到端黑盒）。

结语

未来几年的真实格局是分层的：旗舰走原生（赌上限），垂直场景和端侧继续用拼接（赌性价比）。"原生替代拼接"不是一夜革命，是从高端开始的缓慢渗透——就像电动车替代燃油车，先从豪华车开始。

一起长大的孩子，和后天请的翻译，理解力不在一个维度。

但请翻译便宜、快、够用。为"原生"付费之前，先算清楚你的任务到底在交多少翻译税：任务越依赖细节（OCR、缺陷检测、医疗影像），越要偏原生；只是"图里大概是什么"，拼接式完全够用。视频任务，直接排除纯拼接路线——时序+音频联合是它的结构性短板，不是调参能补的。
