# 二、Encoder-Decoder 回归：为什么"开倒车"

2020 年 T5 之后，主流是 Decoder-only（GPT 系列）。DeepSeek 用回 Encoder-Decoder，看似"开倒车"，实则是**为 RAG 和多模态量身定制的选择**：

```python
# Decoder-only：理解和生成混在一起
#   prompt（含 100K 检索文档）→ 自回归生成
#   问题：每次生成都要重新"理解"一遍 100K 文档

# Encoder-Decoder：理解和生成分开
encoder_out = encoder(documents)     # 双向注意力，一次编码
#   → 编码一次，多次解码复用
for _ in range(n_queries):
    answer = decoder(query, encoder_out)   # 只解码，不重编码
```

三个收益：

1. **双向理解**：编码器看全文（双向注意力），**理解准**——Decoder-only 的因果掩码，注定"后文看不见前文"的反方向不行；
2. **RAG 省钱**：100K 文档编码一次，后面 100 个问题复用——**省 50%+ 计算**；
3. **多模态天然对齐**：图像进编码器，文本进解码器，**跨模态注意力就是对齐本身**，不用外挂投影层。

**架构没有"先进"和"落后"，只有"合适"和"不合适"。** Decoder-only 赢在"通用"，Encoder-Decoder 赢在"检索增强和多模态"——V4.1 赌的是后者是更大的市场。

# 三、3% 测了什么，没测什么

```
测了的（基准分数）：MMLU、GPQA、SWE-Bench、ARC……
  → 差距 3%，约等于打平

没测的：
  生态：CUDA vs 国产卡，HuggingFace vs 国内镜像，vLLM 插件丰富度
       → 差距依然大。分数能追，生态要 3-5 年
  算力：H100 禁运，靠昇腾 + 效率优化
       → 单卡不如，但系统级（SuperPoD）在追
  人才：回流 + 本土培养
       → 差距缩小最快的一项
```

**"3%"是个基准数字，不是实力数字。** 真实世界的 AI 竞争，基准只占 30%——剩下 70% 是芯片、框架、开发者生态、商业落地。V4.1 的 3% 证明"能考高分"，但"考高分"和"建生态"是两场不同的比赛。
