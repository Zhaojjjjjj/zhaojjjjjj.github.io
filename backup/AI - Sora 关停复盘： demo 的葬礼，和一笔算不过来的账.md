> 先说一个反常识的结论：**关停 Sora，可能是 OpenAI 近两年最正确的决定。** 这话 2024 年说会被当疯子——那年 Sora 的 60 秒 demo 让全世界相信"世界模型"来了。但站在今天回头看，Sora 的死亡剧本在它最风光那天就已写好：不是死于技术不行，是死于一笔从第一天就没算过来的账。

# Sora 关停复盘： demo 的葬礼，和一笔算不过来的账

```
2024 年初：Sora 发布，60 秒 demo 震惊世界
2024 年底：正式上线，排队加付费
2025 年秋：Sora 2 配独立社交 App，五天百万下载
2026 年 3 月：宣布逐步关停——应用、API、网站全关，
              算力和人才转向"生产力工具"
```

高开，低走，再见。科技史不缺短命产品，但很少有哪个像 Sora 这样开局即巅峰、步步聚光灯下，最后退场几乎没人惋惜。人们惋惜的只是那个 demo，不是这个产品——**这两者的区别，正是 Sora 故事的全部**。

# 一、死因一：成本黑洞——刚性成本撞上社交 ARPU

视频生成的算力是文本的百倍量级，不是比喻是物理：文本一个 token 一个 token 吐，视频每一帧每个像素都要从噪声里"雕"出来。60 秒、24 帧、1080p，乘一下就知道量级。

Sora 2 的社交 App 越火，黑洞转得越快：**每个用户都在烧钱**。五天百万下载翻译成财务语言是"每天烧掉一个 H100 集群"——用户看一条短视频贡献几分钱广告费，你为他生成一条花几美元，**等式第一天就是反的**。

更残酷：成本不随规模下降。文本模型有规模效应，用户越多单位成本越低；视频生成成本刚性，每多一次生成就多一份实打实支出。**用户规模在这里不是解药，是毒药。**

# 二、死因二和三：没有 PMF，三线全输

人们玩 Sora 是尝鲜，不是刚需。下载炸裂、留存惨淡：生成三条"宇航员骑马"发朋友圈收一波赞，然后走了。**生成视频不是社交，社交是人和人。** 把生成器套上社交的壳，改变不了本质——没人每天打开一个 App 是为了"生成"。demo 让人"哇"，但"哇"之后呢？用户第二天打开的理由是什么？想不清这个，下载曲线越陡跌得越惨。

同时三线作战、三线全输：**画质线**，Veo 3 更好还长在 YouTube 生态里——分发即入口，Sora 还在让人"来我的 App"，对手已把生成器塞进用户本来待着的地方；**价格线**，国产可灵、海螺便宜一个数量级，效果导向的商品用户只认"同样效果谁便宜"；**生态线**，Sora 始终是个"生成器"，对手卖的是工作流一环——剪辑、素材、发布。**贵、慢、没生态，六个字就是墓志铭。**

最后一根稻草来自内部：IPO 前要讲"赚钱"的故事，砍掉烧钱的 Sora，把算力和最贵的人才调去企业服务和 Agent。**敢砍掉自己最出圈的 demo 团队，是一家公司成熟的标志**——2024 年需要 Sora"秀肌肉"，2026 年需要利润表"算账"。

# 三、技术路线的反思："生成"不赚钱，"解决"才赚钱

纯看技术，Sora 押的是 **DiT 从零生成**：给文字，从噪声扩散出整段视频。2024 年最性感，2026 年回头看，赢的是"混合路线"——Veo 3 生成加编辑加真实素材混合，不追求从零造世界；更远处还有"代码生成视频"：模型输出动画代码，浏览器渲染，成本是 DiT 的零头。

Sora 证明了一件事：**用户不会为"生成"付费，只会为"解决"付费**。Sora 到底解决了谁的什么问题？诚实答案：没有。它解决的是"哇，好酷"——而"好酷"是情绪，不是问题。情绪不能续费。

如果重来，三条活路：**别做社交做工具**——API-first，做剪辑师 Copilot、广告素材引擎，用户为"省下的工时"付费，成本账算得过来，工具按效果收费，社交按注意力收费，视频生成的成本结构只配做前者；**降本不堆画质**——用户对画质边际感知递减，"惊艳"到"更惊艳"不值得付费，把一半研发从画质挪到成本，单次成本降一个数量级很多模式就成立，**在成本刚性的赛道里，降本就是创新**；**借生态别建生态**——独立 App 最重，获客留存内容全从零建，Veo 3 赢在"长在 YouTube 里"，**没分发优势的产品不配谈独立 App**。

# 结语

关停不是扔进垃圾桶，是资源再分配：**算力去哪了**——转向企业服务和 Agent，H100 小时从"用户的一次哇"变成"客户的一张发票"，算力流向就是战略流向；**人才去哪了**——做过 Sora 的团队是全世界最懂大规模多模态推理优化的人之一，技术遗产以"能力模块"活在别的产品里，关停的是产品，沉淀的是人；**对创业者**——巨头退出"纯视频生成"是警告不是机会，"再做一个 Sora 但更好"是最贵的死法，连 OpenAI 都算不过来账。

2026 年后视频生成不会死，但"视频生成产品"会死。活下来的只会是"解决问题"的形态：剪辑 Copilot、广告素材流水线、游戏资产管线——退化成工作流里的一个环节。**"生成一段很酷的视频"本身，从来就不是一门生意。** Sora 用两年和天文数字算力替全行业交了学费：AI 从"秀肌肉"转向"算账"的 2026 年，它是第一个交卷的，也是学费最贵的。
