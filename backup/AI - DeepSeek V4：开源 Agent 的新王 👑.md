> 2026 年 4 月 24 日，DeepSeek 发布 V4 预览版并开源（V4-Pro / V4-Flash）：100 万 token 上下文，Agent 能力开源最佳，V4-Pro 体验接近 Opus 4.6。从 R1 到 V4，DeepSeek 用 15 个月走完了别人 3 年的路。这篇聊聊 V4 的技术。

## V4 的配置

```
V4-Pro：旗舰，Agent 能力对标 Opus 4.6（非思考模式）
V4-Flash：快版本，成本极低
上下文：1M tokens
开源：权重开放（延续 DeepSeek 的 openness 战略）
```

**Agent 能力开源最佳**——这是第一次，开源模型在 Agent 任务上摸到闭源旗舰的屁股。

## 为什么 Agent 能力强

DeepSeek 的 Agent 配方（从 R1 到 V4 一脉相承）：

1. **长程 RL**：不是单轮问答的 RL，是**多轮工具调用**的 RL。奖励 = "任务完成"，不是"答案像不像"。V4 的 RL  rollout 长达数百步——**在模拟环境里"实习"了上亿次**。
2. **工具数据**：训练时见过海量"调用工具→观察结果→调整"的轨迹。MCP 生态爆发后，这类数据管够。
3. **1M 上下文**：Agent 要记住几十轮的工具结果，上下文就是工作记忆。V4 的 1M 不是噱头，是 Agent 的刚需。

## 开源的连锁反应

V4 开源后 30 天：

- HuggingFace 上 500+ 微调版。
- 私有化 Agent 落地爆发：金融、政务——数据不出内网，能力对标闭源。
- **价格战**：V4-Flash 的 API 定价把推理成本再砍一半，闭源厂商被迫跟进。

## DeepSeek 的方法论

复盘 DeepSeek 的 15 个月：

```
V3（2024-12）：FP8 + MLA，极致性价比
R1（2025-01）：GRPO，开源推理
V3.2（2025-09）：RL 后训练
V4（2026-04）：长程 RL + 1M 上下文，Agent 之王
```

**每一步都踩在"工程极致主义"上**：不追参数，追性价比；不藏着，写报告。V4 是这套方法论的集大成。

## 一句话总结

V4 证明：**开源不是"便宜版"，可以是"最强版"**。当 Agent 成为 AI 的主要形态，开源 Agent 模型就是基础设施——像 Linux 之于服务器。DeepSeek 在做的，是 Agent 时代的 Linux。
