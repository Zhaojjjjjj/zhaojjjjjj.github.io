> Claude Haiku 4.5 发布于 2025 年 10 月 15 日：性能接近 Sonnet 4，速度快 2 倍，成本只要 1/3。"小杯"第一次有了"超大杯"的体验。这篇讲讲背后的核心技术：知识蒸馏。

## 蒸馏是什么

```
老师（Sonnet 4，超大）：什么都会，但又贵又慢
学生（Haiku 4.5，小）：向老师学习，目标是"学到 90% 的能力，只要 30% 的成本"
```

不是让小模型自己从零学，而是**站在大模型的肩膀上**：大模型已经见过海量数据、学会了推理，小模型直接学它的"输出分布"，而不是从原始数据重新学。

## 为什么学"分布"比学"答案"好

传统训练：

```
输入："1+1=?" → 目标答案："2"（one-hot，信息量极低）
```

蒸馏训练：

```
输入："1+1=?" → 老师输出："2"(0.97), "二"(0.02), "two"(0.01)
```

老师的**软标签**包含了"暗知识"："2"和"二"很像，"2"和"苹果"完全不像。这些细微的相似度信息，是 one-hot 标签永远给不了的。学生学到的不只是答案，是老师的"认知结构"。

## 蒸馏的三种配方

1. **黑盒蒸馏**（最常用）：只用老师的输出（API 就行）。Seed 数据 → 老师生成答案 → 学生模仿。2025 年大部分"小模型"都是这么来的。
2. **白盒蒸馏**：能拿到老师的中间层、注意力权重。对齐 hidden states，学得更深，但需要老师权重。
3. **序列级蒸馏**：不只学单 token 分布，学整句的生成轨迹。对 Agent、代码这种长程任务特别有效——Haiku 4.5 的代码能力就是这么保住的。

## 温度：蒸馏的超参

```python
# softmax 温度越高，分布越"软"，暗知识越多
soft_targets = softmax(teacher_logits / T)  # T=2~5 常用
loss = KL(student_logits / T, soft_targets) * T^2 + CE(student, hard_labels)
```

T 太小≈硬标签（白蒸馏了），T 太大≈均匀分布（学不到东西）。**T 是蒸馏第一超参**。

## 争议：蒸馏 vs "抄"

2025 年 9 月美方指控中国公司"蒸馏"美国模型，10 月 Haiku 4.5 发布——时间线很微妙。但技术上要分清：

- **Anthropic 蒸馏自己**：老师和学生都是自家的，合法合规。
- **蒸馏竞品**：用 GPT-4 的 API 输出训自己的模型——违反 ToS，灰色地带。

## 一句话总结

蒸馏的本质是"知识压缩"：把大模型的认知，压进小模型的身体。Haiku 4.5 证明，**好的学生能学到老师 90% 的功力**。2025 年下半年的趋势很清楚：旗舰模型负责"探索上限"，蒸馏出的小模型负责"落地赚钱"。
