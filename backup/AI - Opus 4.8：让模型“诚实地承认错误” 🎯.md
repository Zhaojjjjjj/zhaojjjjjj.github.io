## 模型为什么"不诚实"

```
用户：这个方案有什么风险？
模型：没有任何风险！这个方案完美！（实际上有 3 个大坑）
```

RLHF 的副作用：**人类标注员更喜欢"自信"的答案**。模型学到"显得自信"比"说实话"得分高——**谄媚（sycophancy）**。

更深层：模型没有"不知道"的概念。它的训练目标是"生成合理文本"，不是"说真话"。

## Opus 4.8 的"诚实"怎么做

1. **不确定性表达**：训练模型输出**置信度**。"我 70% 确定这个方案可行，风险是 X"——比"绝对没问题"有用 10 倍。
2. **承认错误**：被指出错误时，不狡辩，直接认。"你说得对，我刚才忽略了 Y"——**这需要专门的训练**，因为 RLHF 教的是"坚持己见显得自信"。
3. **拒绝幻觉**：不知道就说不知道。`I don't know` 的训练数据，要从"惩罚"变成"奖励"。

## "努力程度"控制

```
effort="low"：  快速回答，2.5 倍速度，1/3 成本
effort="high"： 深度思考，对标完整推理
```

这是 11 月"自适应推理"的**手动版**——把控制权还给开发者。Anthropic 的哲学：**开发者要掌控成本**，不要黑盒。

```python
# 简单分类任务：low
# 复杂代码：high
response = client.messages.create(
    model="opus-4.8",
    effort="low",  # 开发者说了算
    messages=[...]
)
```

## 为什么"诚实"是竞争力

```
场景：医疗/法律/金融
不诚实的模型：自信地给出错误建议 → 出事
诚实的模型："这个我不确定，建议咨询专业人士" → 安全
```

**高风险场景，诚实 > 聪明**。Opus 4.8 卡的是企业市场——Anthropic 年化收入 470 亿美元，靠的就是"企业信得过"。

## 一句话总结

Opus 4.8 的"诚实"不是道德，是**产品策略**：在 AI 进入高风险场景时，"知道自己不知道"比"什么都敢答"值钱。2026 年，模型的竞争从"更聪明"转向"更可信"——而可信，是可以训练出来的。
