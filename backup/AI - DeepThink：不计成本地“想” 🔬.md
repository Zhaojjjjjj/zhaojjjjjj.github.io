## DeepThink 是什么

```
普通模型：快思考，秒回，适合日常
DeepThink：慢思考，可以"想"几分钟到几小时，适合科研
```

类比：普通模型是"急诊医生"，DeepThink 是"会诊专家团"。它不追求速度，追求**深度的正确**。

## 技术：极端 test-time compute

DeepThink 的配方：

1. **超长思考预算**：100K+ tokens 的思考过程。是 o1 的 10 倍。
2. **多路径探索**：同时展开几十条推理路径，像围棋的 MCTS。
3. **工具循环**：思考中调用代码执行、文献检索、数值计算——**边想边验证**。
4. **自我批判**：专门的"批评家"子过程，挑主推理的毛病。

HLE（Humanity's Last Exam）48.4% 无工具——这是博士级考试，**人类专家平均也就 30-40%**。DeepThink 超过了出题人。

## 科研场景

- **数学证明**：Lean 形式化，自动证明引理。
- **药物发现**：分子性质预测，实验方案设计。
- **物理模拟**：参数空间搜索，异常解释。

共同点：**答案的价值 >> 等待的成本**。一个新药靶点值 10 亿美元，多等 2 小时算什么。

## 成本账

```
DeepThink 一次查询：~$50-200（100K thinking tokens）
普通查询：~$0.01
```

**贵 10000 倍**。所以它的商业模式不是 API 按量，是**按项目收费**——药企、实验室包年。这是"模型即专家"的定价。

## 一句话总结

DeepThink 代表推理模型的终极形态：**不计成本地想**。它证明了"思考"是可以无限加码的，而加码的回报在科研场景是超线性的。2026 年，AI 从"助手"变成了"同事"——而 DeepThink，是那个最聪明的同事。
