> 2026 年 7 月 8 日，TypeScript 7.0 GA：编译器整体从 TS 移植到 Go（代号 Corsa），全量类型检查 8-12 倍加速；`strict` 默认开启。这是 TS 历史上最大的一次重构。这篇聊聊。

## 为什么用 Go 重写

```
TS 编译器（TS 写的）：单线程，类型检查 100 万行代码要 2 分钟
Corsa（Go 写的）：多线程，同样代码 15 秒
```

**8-12 倍**。不是优化，是换语言。

为什么是 Go：

1. **并发**：goroutine 轻量，类型检查天然可并行（文件之间独立）。
2. **编译快**：Go 编译器秒级，Rust 要分钟级——**开发体验**。
3. **团队**：TS 团队在微软，Go 也是微软重仓（VS Code、TypeScript 团队有 Go 经验）。

## 8-12 倍从哪来

1. **并行**（3-4x）：16 核全开，文件级并行。
2. **增量**（2-3x）：更细粒度的缓存，改一个文件只重查相关的。
3. **Go 本身**（1.5x）：AOT 编译，无 GC 停顿（Go 的 GC 比 V8 轻）。

**3×2×1.5 ≈ 9x**——和官方的 8-12x 对得上。

## strict 默认开启

```json
// tsconfig.json（7.0 之前）
{
  "compilerOptions": {
    "strict": true  // 要手动开，很多人没开
  }
}

// 7.0：默认就是 strict，新项目不用写
```

**影响**：老项目升级，第一次 `tsc` 会爆出一堆错——**不是退化，是之前没查出来**。微软给了迁移工具：`tsc --fix-strict` 自动修一部分。

## 对开发者的影响

1. **CI 快了**：类型检查从 2 分钟到 15 秒，**流水线瓶颈消失**。
2. **编辑器快了**：VS Code 的 TS Server 换 Corsa，**大项目不卡了**。
3. **生态**：babel、esbuild、swc 都是"转译"（不管类型），**类型检查还得 tsc**——Corsa 让 tsc 重新有竞争力。

## 迁移指南

```bash
# 1. 升级
npm i -D typescript@7

# 2. 跑检查，看 strict 爆出多少错
npx tsc --noEmit

# 3. 逐步修（别一次全修，用 // @ts-expect-error 标记）
# 4. 跑测试，确保没 break
```

**大部分项目 1 天内迁完**。类型更严，但代码更对。

## 一句话总结

TS 7.0 是"**基础设施的胜利**"：编译器快 10 倍，开发体验质变。2026 年，工具链的 Go/Rust 化完成——**JS 写的工具，正在被编译型语言取代**。记住：strict 默认开，是 TS 团队在替你还债——早还早轻松。
