> 2026 年 7 月，华为昇腾 Atlas 950 SuperPoD 在 WAIC 首秀：单机柜 8192 张昇腾 950DT 卡互联，FP8 算力 8 EFLOPS，业界最大规模超节点。这篇聊聊"超节点"的互联工程。

## 8 EFLOPS 是什么概念

```
1 EFLOPS = 每秒 100 亿亿次运算
8 EFLOPS = 8 × 10^18
≈ 10 万张 H100（FP8）
```

**单机柜，10 万张 H100 的算力**。2024 年，这需要一整个数据中心。

## 超节点的难点：互联

```
8192 张卡，每张都要和其它 8191 张通信
→ 全互联需要 3300 万条链路（不可能）
```

**拓扑**是超节点的灵魂：

1. **Dragonfly / Fat-Tree**：分层，卡→交换机→核心交换机。**跳数少，但交换机贵**。
2. **昇腾的方案**：自研互联协议（类似 NVLink 的国产版），**单机柜内全互联**，机柜间走光互联。

**带宽**：

```
卡间带宽：~900GB/s（对标 NVLink）
→ 8192 卡的 all-reduce，一次同步 10GB 数据，只要 0.1 秒
```

## 为什么做超节点

```
传统：1000 个机柜，每个 8 卡 → 机柜间通信慢（100GB/s）
超节点：1 个机柜，8192 卡 → 全高速互联（900GB/s）
```

**万亿模型训练，通信是瓶颈**。超节点把"慢网络"变成"快网络"，**训练效率从 30% 提到 50%+**。

```
100 天训练：
效率 30% → 实际 333 天
效率 50% → 实际 200 天
→ 省 4 个月，省上亿电费
```

## 国产算力的意义

```
2024：H100 禁运，国产卡"能用"
2025：昇腾 910C，对标 H100 60%
2026：950DT SuperPoD，单机柜 8 EFLOPS
```

**从"追赶"到"并跑"**。超节点是系统工程——卡、互联、软件栈全自研。这是**算力自主**的里程碑。

## 对开发者的影响

1. **国产卡能训大模型了**：PyTorch 适配、CANN 优化，**生态在补齐**。
2. **成本**：昇腾的性价比是 H100 的 1/3——**预算有限的团队的新选择**。
3. **多云**：以后租卡，不只有英伟达。

## 一句话总结

SuperPoD 是"**互联的胜利**"：8192 张卡拧成一股绳。2026 年，算力的竞争从"单卡多强"转向"系统多强"——卡、网、软件，缺一不可。记住：**大模型的 scaling law，底层是互联的 scaling law**。
