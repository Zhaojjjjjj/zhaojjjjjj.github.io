> 2025 年底，GLM-4.6V、Kimi K2.5 等视觉推理模型密集发布。它们不只是"能看图"，而是"看着图思考"——视觉和推理的第一次真正融合。这篇讲讲视觉推理的技术。

## 从"看图说话"到"看图思考"

```
2024：VLM = "这张图里有什么？"（描述）
2025年底：视觉推理 = "看着这张电路图，找出短路点，并解释电流路径"（推理）
```

区别：前者是**感知**，后者是**感知+推理的交织**。模型要在视觉 token 和文本 token 之间来回跳：看一眼图，想一步，再看一眼，再想一步。

## 技术关键：交错注意力

```
传统：[图像 tokens] → [文本 tokens]（单向，先看后说）
视觉推理：[图1] → [想1] → [图2放大] → [想2] → [结论]（交错）
```

模型学会了**主动回看**：推理到关键步骤时，重新关注图像的相关区域。类似人类的"边看边想"——做数学题时眼睛在题目和草稿纸之间来回扫。

训练数据是"视觉思维链"：

```
图像 + 问题 → [看左上角] → [这里有个电阻] → [阻值是 10Ω] → [所以电流是...] → 答案
```

## 为什么现在才work

1. **上下文够长**：交错推理的 token 消耗是纯文本的 3-5 倍，128K+ 上下文是前提。
2. **原生多模态**（见 11 月那篇）：拼接式架构做不好交错，只有原生多模态能让视觉和文本真正"对话"。
3. **RL 奖励**：用"答案对不对"做奖励，模型自己学会"什么时候该回看图像"。

## 应用场景

- **工业质检**：看电路板照片，推理出故障点。
- **医疗影像**：看 CT，逐步推理病灶（辅助，不是替代医生）。
- **UI 测试**：看 App 截图，推理出交互 bug。
- **教育**：看几何题图，一步步讲辅助线怎么画。

## 一句话总结

视觉推理是"多模态"和"推理"两条路线的交汇点。2025 年它们分别成熟，年底终于合流。2026 年的 Agent 会是"长眼睛"的——能看屏幕、能读图表、能理解真实世界。而这一切，从 GLM-4.6V 和 Kimi K2.5 开始。
