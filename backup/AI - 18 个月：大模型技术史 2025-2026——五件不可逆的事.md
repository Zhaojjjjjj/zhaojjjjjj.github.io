> 2025 年 4 月到 2026 年 9 月，18 个月，72 篇。这个系列从 MCP 写到 GPT-6，从 SSE 的 bug 写到 MoE 的通信。完结篇不打算做"盘点"——盘点是把旧菜热一遍。我想回答一个真问题：**这 18 个月里，到底发生了几件"不可逆"的事？**

# 18 个月：大模型技术史 2025-2026——五件不可逆的事

"不可逆"的定义：发生之后，行业再也回不去。18 个月里，我数出来五件。

# 一、推理从"能力"变成"商品"（2025-04 → 2026-09）

```
2025-04：o3 发布，"测试时计算"是前沿概念，thinking 按分钟计费
2026-09：GPT-6 Astra 98.6% ARC-AGI-3，推理是默认项，无人再讨论"要不要思考"
```

这 18 个月，推理走完了"奢侈品 → 标配 → 商品"的全程：

- **2025 年中**：过度思考（overthinking）问题爆发——模型为 1+1 烧 8000 tokens，人们第一次问"思考值多少钱"；
- **2025 年底**：自适应推理（GPT-5.1）+ 努力程度控制（Opus 4.8）——"想多深"变成可调参数；
- **2026 年**：思维链压缩、推测解码、Flash 定价——**思考的成本降了 10 倍，质量没变**。

不可逆的点在于：**一旦"思考"有了价格，它就再也不是"能力"，而是"成本项"**。2026 年的架构评审里，"这个任务需要多少 thinking tokens"和"需要多少内存"出现在同一张表上。推理完成了它最重要的转变——从论文里的概念，变成账本里的一行。

# 二、架构从"一招鲜"变成"混合制"（2025-07 → 2026-07）

```
2025-07：Kimi K2，1T MoE —— "MoE 是答案"
2026-07：Kimi K3，2.8T，线性+全注意力混合 —— "没有唯一答案"
```

18 个月前，争论的是"Dense 还是 MoE"；18 个月后，K3 的架构是**MoE（管容量）+ 线性注意力（管效率）+ 全注意力（管精度）+ 稀疏（管成本）**的四合一。

不可逆的点：**"纯架构"的时代结束了**。就像 CPU 从"单核"变成"大小核 + NPU + GPU"的异构，模型架构也进入了"为每一层、每一个 token 选刚好够的计算"的精细化时代。再也没有人问"最好的架构是什么"——**标准答案变成了"看场景"。**

# 三、开源从"追赶"变成"并跑"（2025-01 → 2026-09）

```
2025-01：R1，"开源居然能打"
2026-04：V4，"开源 Agent 之王"
2026-09：V4.1，基准差距 3%，MIT 协议
```

数字上是 20% → 3%，但真正的不可逆发生在**商业模式**上：

- **2025**：开源 = "便宜版"，靠价格战抢市场；
- **2026**：开源 = "基础设施"，DeepSeek 把训练细节全公开，用 openness 当护城河；
- **2026-09**：V4.1 MIT 开源——**"拿去赚钱不用打招呼"**，开源从"策略"变成"信仰"。

不可逆的点：**当最强的模型之一选择 MIT，开源就不再是"备选"，而是"默认"。** 闭源厂商被迫回答一个 2024 年不用回答的问题："凭什么闭源？"——而 2026 年的答案越来越难找。

# 四、Agent 从"调 API"变成"用电脑"（2025-04 → 2026-09）

```
2025-04：MCP 统一"模型调工具"的接口 —— Agent 的 USB-C
2025-09：Sonnet 4.5 Computer Use —— 模型开始"看屏幕点鼠标"
2026-03：GPT-5.4 原生 Computer Use —— 操作电脑变成第一公民
2026-08：GLM-5.3 Terminal-Bench 28.3 —— 终端里独立干活
```

这条线的每一步都在回答同一个问题：**Agent 的"手"能伸多远？** 从"调 API"（MCP）到"用电脑"（Computer Use）到"在终端里当工程师"（Terminal-Bench），**"手"的边界就是 Agent 的能力边界**。

不可逆的点：Anthropic 的 Managed Agents 论文（2026-04）把这件事理论化了——Brain（决策）、Hands（执行）、Session（记忆）三权分立。从那之后，**"Agent = while(true) 调模型"这种写法，在生产环境里死了**。任何 serious 的 Agent 系统，都要回答三个问题：崩了怎么恢复？凭证怎么隔离？上下文满了怎么办？——答不上来，就是 demo。

# 五、工程从"追新"变成"还债"（贯穿 18 个月）

这 72 篇里，有 20 篇是 bug 复盘和工程实践：SSE 卡住、Node 内存泄漏、WebSocket 心跳、Redis 三连击、CORS、Nginx 502、时区 bug、Docker 瘦身……

它们和 AI 主线看似无关，但 18 个月后回头看，**这些是最"保值"的部分**：

```
2025-04 的 MCP：到 2026-09 还是 Agent 基础设施 —— 保值
2025-06 的 Node 内存泄漏排查：10 年后还管用 —— 保值
2026-09 的 GPT-6：3 个月后被下一代取代 —— 折旧
```

不可逆的点（或者说，被验证的点）：**追热点的文章折旧最快，讲机制的文章最保值**。MCP 之所以保值，不是因为它"新"，是因为它解决的是"连接"这个永恒问题；Node 内存泄漏保值，是因为"引用"这个概念永恒。**技术的半衰期，取决于它离"第一性原理"有多近。**
