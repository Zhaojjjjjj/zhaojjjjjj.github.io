> Claude Sonnet 4.5 发布于 2025 年 9 月 29 日，官方强调它是"复杂智能体与 Computer Use 能力最强"的模型——能看屏幕、点鼠标、敲键盘，连续工作 30 小时。这篇拆解 Computer Use 的技术栈。

## Computer Use 是什么

不是"调 API"，是**真·操作电脑**：

```
模型看到：屏幕截图（像素）
模型输出：mouse.move(x, y) / click / type("hello") / key("Enter")
```

没有 DOM、没有 accessibility tree——纯视觉。2024 年 10 月 Sonnet 3.5 首次演示，2025 年 9 月的 4.5 把它做到了可用。

## 技术栈三件套

1. **视觉 grounding**：把"点那个蓝色按钮"翻译成屏幕坐标 (x, y)。这是最难的部分——UI 元素没有语义标签，模型要从像素里"看"出可点击区域。训练数据是海量"截图+点击位置"对。
2. **动作空间**：click / double-click / drag / scroll / type / hotkey。离散化成 token，模型像说话一样"说"出操作。
3. **状态机**：每次动作后重新截图，判断"做完了吗"。失败重试、死循环检测——和前面 Agent 篇讲的 ReAct 循环是同一套，只是 action 变成了鼠标键盘。

## 为什么 30 小时专注是质变

之前的 Computer Use 只能做 5 分钟任务：填个表单、点几下。4.5 能跑 30 小时，意味着：

- **错误恢复**：弹了个 unexpected dialog，模型能自己关掉继续，而不是崩。
- **长程记忆**："第 3 步下载的文件，第 28 步要用"——跨几十步的指代。
- **任务分解**："做一份财报"自动拆成：找数据→开 Excel→填表→画图→发邮件。

## 工程落地的问题

1. **慢**：每步都要截图+推理，一个点击 3-5 秒。人类 1 分钟的事，Agent 跑 20 分钟。
2. **贵**：截图是图像 token，30 小时任务的 token 账单很刺激。
3. **安全**：让 AI 点鼠标=给它你的电脑。沙箱、操作白名单、人工确认缺一不可。
4. **脆弱**：UI 改版、弹窗、验证码——真实世界的"脏"比 demo 多 100 倍。

## 一句话总结

Computer Use 是 Agent 的"最后一公里"：从"调 API"到"像人一样用电脑"。Sonnet 4.5 把可用时长从分钟级拉到小时级，但离"放心交给它"还有三座大山：速度、成本、安全。2025 年它是 demo 明星，2026 年看它能不能进生产线。
