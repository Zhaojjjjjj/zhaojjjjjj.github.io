> 2026 年 3 月上旬，OpenAI 发布 GPT-5.4，原生集成 Computer Use；OpenClaw 创始人 Peter Steinberger 同期加入 OpenAI。这不是巧合——这是 OpenAI 的 Agent 总攻。这篇聊聊"原生" Computer Use 和之前有什么不同。

## 从"外挂"到"原生"

```
之前（Sonnet 4.5 时代）：Computer Use 是"能力插件"
→ 模型 + 截图工具 + 鼠标驱动，拼起来的

GPT-5.4：Computer Use 是"第一公民"
→ 训练时就见过"屏幕+操作"数据，推理时原生输出动作
```

区别：

1. **延迟**：外挂式每步要"截图→编码→推理→解码动作"，4-6 秒；原生式动作是 token 流的一部分，**1-2 秒**。
2. **连贯性**：原生模型"记得"自己上一步点了哪，**操作有记忆**；外挂式每步都是新的开始。
3. **泛化**：训练见过 10 万种 UI，原生模型对没见过的软件也能"蒙对"。

## OpenClaw 的拼图

Peter Steinberger（OpenClaw 创始人）加入 OpenAI，信号很明确：

- OpenClaw 是 2025 年最火的开源 Agent 框架（让 AI 操作本地电脑）。
- OpenAI 收编的不是一个人，是**一整套"AI 操作电脑"的工程经验**：沙箱、权限、工具生态。

## "超级应用"：桌面端+Codex+浏览器三合一

3 月中旬，OpenAI 把三个产品合并：

```
ChatGPT 桌面端（对话）
+ Codex（写代码）
+ 浏览器（上网+操作）
= 一个能"动手"的 AI 入口
```

**战略**：从"聊天窗口"到"操作系统"。用户不再"问 AI"，而是"让 AI 干"。

## 工程挑战

1. **安全**：AI 能点鼠标=能删文件、能转账。**操作分级**（只读/写入/危险）+ 人工确认，缺一不可。
2. **可靠性**：UI 一改版就翻车。解法：**语义定位**（"点提交按钮"）而不是坐标定位（"点 (1024, 768)"）。
3. **成本**：每步都是多模态推理，30 分钟任务烧 $10+。**只在高价值场景用**。

## 一句话总结

GPT-5.4 的 Computer Use 标志着：**Agent 从"调 API"进化到"用电脑"**。2026 年的竞争不在模型，在"谁的操作系统里有 AI"。OpenAI 在造"AI OS"，Anthropic 在造"AI 员工"——两条路，同一个终点。
