# V4-Flash-Vision：开源视觉推理的"水桶机"

2026 年 8 月 21 日，DeepSeek-V4-Flash-Vision-Exp 上线 API；8 月 31 日，MIT 开源。这是 2026 年 8 月开源社区最重要的发布之一：第一个"能打"的开源视觉推理模型，而且是最宽松的 MIT 协议。

# 一、在此之前，"便宜"和"能看"互斥

```
要便宜 → 纯文本 Flash（每百万 token 几毛钱，但看不见图）
要视觉 → Pro Vision（贵 10 倍，图像 token 烧钱）
```

视觉为什么贵？一张 1024×1024 的图，切成 patch 进模型，是 **1000+ 个图像 token**——相当于 3000 个文本 token。而视觉任务（质检、打标、文档解析）恰恰是**高频、批量、对单次质量要求不高**的场景。**用 Pro Vision 跑 100 万张产品图，账单是 $2000；用 Flash Vision，是 $200。** 10 倍差价，决定了一个场景能不能做。

# 二、视觉蒸馏：2026 年的新课题

文本蒸馏大家都会了（老师输出文本，学生模仿）。**视觉蒸馏难在哪？**

```python
# 文本蒸馏：输出是离散的 token 分布
teacher_logits = teacher(text)            # [vocab_size]
student_loss = KL(student(text) / T, teacher_logits / T)

# 视觉蒸馏：输出包含"图像理解"，没有显式的"答案分布"
# 老师"看到"了什么？——藏在中间层里，不在输出里
```

V4-Flash-Vision 的路线（从公开信息看）：**V4-Pro-Vision 当老师**，不只蒸馏最终答案，还蒸馏"视觉-文本对齐"的中间表示——

1. **对齐蒸馏**：老师把"图像 patch"和"文本 token"对齐的方式（cross-attention 的权重分布），学生模仿。**学的不只是"答案"，是"怎么看"。**
2. **动态分辨率**：小图用低分辨率（16×16 patch，省 token），细节图用高分辨率（32×32）。**token 预算花在刀刃上**——这不是蒸馏，是工程，但省的钱一样实在。
3. **任务蒸馏**：在视觉问答、文档解析、UI 理解等具体任务上，用老师的输出当标签。**垂直任务的蒸馏，比通用蒸馏保真度高得多。**

# 三、MIT 协议：为什么是"成人礼"

开源协议的光谱：

```
开放权重（Llama 式）：能下载，不能商用（或受限商用）
Apache 2.0：         能商用，但有专利条款
MIT：                最宽松，拿去赚钱不用跟任何人打招呼
```

V4-Flash-Vision 选 MIT，信号很明确：**DeepSeek 不靠这个模型赚钱，靠生态**。100 万张产品图的质检场景里，创业公司可以直接把 V4-Flash-Vision 塞进自己的 SaaS 按月收费——**MIT 意味着"拿去赚钱"，这是开源的终极形态。**

对比 2025 年的 gpt-oss（Apache 2.0）和 Llama 系列（定制协议）：**协议越宽松，生态越大**。2026 年 8 月，开源视觉推理的竞争，V4-Flash-Vision 用 MIT 直接定了调。
