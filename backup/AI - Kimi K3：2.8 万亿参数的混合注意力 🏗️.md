## 2.8T 是什么概念

```
Kimi K2（2025-07）：1T 总参
Kimi K3（2026-07）：2.8T 总参
一年，2.8 倍
```

**开放权重模型的最大规模纪录**。2.8T 的 FP16 权重 = 5.6TB——**存都存不下**（8×H100 才 640GB）。实际部署靠：

- FP8 量化：2.8TB
- 分片：32×H100
- MoE：激活的只有一小部分

## 混合注意力：线性+全注意力

```
全注意力：O(n²)，准，但贵
线性注意力：O(n)，快，但弱（长程依赖差）

K3：大部分层用线性注意力（便宜）
    关键层用全注意力（保质量）
```

**三明治架构**：

```
[线性 × 10 层] → [全注意力 × 2 层] → [线性 × 10 层] → ...
```

直觉：**大部分 token 关系是局部的**（线性够了），只有少数需要全局视野（全注意力兜底）。2025 年的 MiniMax、2026 年的 K3，都在验证这个。

## 为什么混合work

1. **注意力是稀疏的**（见 5 月那篇）：90% 的注意力权重 ≈ 0，线性近似够用。
2. **全注意力层做"校准"**：每隔 10 层来一次全注意力，**纠偏**线性层的误差累积。
3. **KV Cache 砍 80%**：线性注意力的 KV 是常数大小（不是随 n 增长），**1M 上下文的 KV 从 200GB 降到 40GB**。
