> 同一个任务，两套 Computer Use 方案各跑一遍：在航空公司官网订一张下周五北京飞上海的早班机。A 方案是老式外挂流派——模型看截图，再调鼠标驱动去点；B 方案是原生 Computer Use。A 用了 11 分钟，点 63 次，4 次点错弹窗，卡死在支付页滑块验证。B 用了 4 分钟，零点错，还顺手关掉三个营销弹窗。差距不在模型智商，在一件事：**动作是不是模型的"母语"**。

# GPT-5.4 原生 Computer Use：从 demo 到系统

# 一、动作第一次成为"母语"：省掉的是"翻译税"

外挂式的本质是"翻译"：

```
截图 → 图像编码 → 模型推理 → 解码成坐标动作 → 调驱动执行
```

每步走完链条，单步 4 到 6 秒。更要命的是动作是"翻译"出来的——模型想的是"点提交按钮"，说出来变成"点击坐标 (1024, 768)"，中间隔了一层有损转换。窗口一缩放坐标就偏，页面一改版整条链路翻车。

原生把动作写进母语：动作 token 和文本 token 是同一个输出流。模型"想"点提交按钮，输出的就是这个动作，不经过坐标翻译，单步 1 到 2 秒。算账：50 步的任务，外挂式光"翻译税"多交 3 到 4 分钟——还没算翻译错了重来的成本。

**延迟只是表象，真正的分水岭是动作的"第一公民"身份。** 动作成为 token 流的一部分，规划、执行、纠错在同一个推理过程里完成，而不是"想一步、翻译一步、执行一步"的三段式。

# 二、它记得自己点过哪：操作记忆带来纠错与泛化

外挂式有个隐性残疾：**每一步都是新的开始**。看到的永远是全新截图，"上一步点了哪"只能靠提示词里的文字总结——二手、粗糙。复杂多步任务就"失忆"：重复点已点的按钮，忘记关过的弹窗。

原生模型的记忆是连续的：点过哪个菜单、关过哪个弹窗、在哪个输入框填过什么，活在 hidden state 里，是操作记忆的一部分。带来两个质变：

**第一，纠错能力。** 点错了能意识到"刚才那一下没点对"——上一步动作和这步屏幕变化连贯可对比。外挂式点错，往往等整轮超时才发现。

**第二，泛化能力。** 训练见过十万种 UI 的操作数据，学到的是"点右上角 × 关闭弹窗"这类**语义动作**，不是某软件的坐标。第一次打开冷门 OA 系统也能蒙对八成。评估 Computer Use，别只看单系统分数，看**换系统后掉多少分**——掉得少的才是真泛化。

OpenClaw 创始人 Peter Steinberger 同期加入 OpenAI，信号明确：收编的不是一个人，是**一整套"让 AI 操作电脑"的工程经验**——沙箱隔离、权限分级、失败回滚，这些写不进论文，只能从生产事故里熬出来。**Computer Use 的竞争已从"能不能 demo"进入"能不能生产"**，模型只是入场券，壁垒是那一整套工程。

# 三、从 demo 到生产：三道关，和三个反直觉细节

三道关，每道都和模型智商无关：

**第一道：安全。** AI 能点鼠标就等于能删文件、能转账。操作分级：只读随便跑，写入留痕，危险操作（删除、支付、对外发送）必须人工确认；再加沙箱隔离，先在"假电脑"试。没有这套，Computer Use 就是高权限木马。

**第二道：可靠性。** UI 改版就翻车是宿命。解法是**语义定位代替坐标定位**——"点提交按钮"而不是"点 (1024, 768)"，执行前加"操作前校验"。把"一次点对"的期望，换成"点错能发现、能重试"的机制。

**第三道：成本。** 每步都是多模态推理，30 分钟任务烧 10 美元量级是常态。**天生只属于高价值场景**：整理合同、对三个系统的账。务实分层：高价值步骤用原生，低价值重复步骤降级成 API 调用。

三个 demo 里看不到的细节：

1. **截图分辨率不是越高越好。** 1080p 之后准确率提升趋平，token 却翻四倍。生产甜点是"够看清按钮文字"的最低分辨率——**优化第一刀砍在输入上，不在模型上**。
2. **AI 也有"方言"问题。** macOS 训练多的模型操作 Windows 会水土不服，关闭按钮从左跑到右。解法和人类一样：跨平台数据都要见过。
3. **评测正从"做对"转向"做稳"。** 生产指标不是单次准确率，是"**无人值守成功率 × 失败可恢复率**"。demo 拼上限，生产拼下限。

# 结语

落地前三个问题：**这件事必须"看屏幕"吗？**——能调 API 永远优先调 API，Computer Use 是"没有 API 的地方"的补充，不是替代，拿金锄头锄地属于浪费。**失败的代价谁来兜？**——画好 blast radius，dry run 先行，慢一点但睡得着。**成功率几成才算可用？**——95% 是及格线，99% 才敢睡觉；达不到就缩小范围，人机各干各擅长的，**半自动但可靠，比全自动但翻车更接近生产**。

回想开头那场对决：A 输掉的 7 分钟，4 分钟在翻译动作，2 分钟在重复点错，1 分钟卡在滑块——每一种失败都是"动作不是母语"的并发症。

GPT-5.4 真正重要的不是"AI 会点鼠标了"，是**点鼠标第一次有了生产化的可能**：延迟进可用区间、操作有了记忆、背后站着从开源社区收编的工程经验。留一个开放问题：当界面变成人和 AI 共用，哪些操作必须永远留人手里？**操作分级的边界划在哪，可能比模型本身更值得讨论**——AI 点错一个按钮的代价，和点对一万个的收益，永远是同一枚硬币的两面。
