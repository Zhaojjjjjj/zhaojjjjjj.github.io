> 2026 年 6 月 1 日，MiniMax 发布 M3 并开源权重：428B 总参 / 23B 激活，自研 MSA 稀疏注意力，原生多模态，1M 上下文，多榜开源第一。这是 5 月预告的兑现。这篇做实测向拆解。

## 配置

```
总参数：428B
激活参数：23B（每次推理只用 5%）
架构：MSA（MiniMax Sparse Attention）
上下文：1M tokens
多模态：原生（文本+图像+音频）
开源：权重开放
```

**428B 存，23B 算**——MoE 的极致。存储要 800GB+（FP16），但推理的算力只要 23B 的量。

## MSA 实测

5 月那篇讲了稀疏注意力的理论，M3 是第一次大规模实测：

```
Prefill（输入处理）：9.7 倍加速
Decoding（逐 token 生成）：15.6 倍加速
```

**Decoding 加速更狠**——因为 decoding 是 memory-bound（KV Cache 搬运），稀疏化直接砍了 90% 的搬运量。

```python
# 直观对比（100K 上下文，单次推理）
# Dense：KV Cache 200GB，H100 跑 8 秒
# MSA：KV Cache 20GB，H100 跑 0.8 秒
```

## 部署实测

| 精度 | 显存 | 硬件 | 速度 |
|---|---|---|---|
| FP16 | 850GB | 8×H100 | 40 tok/s |
| FP8 | 430GB | 4×H100 | 60 tok/s |
| Q4 | 220GB | 2×H100 / 8×4090 | 35 tok/s |

**Q4 是甜点**：220GB，8 张 4090（24GB×8=192GB，不够）→ 实际要 2×H100 或 Mac Studio 集群。**个人玩家还是够不着**，但中小公司可以了。

## 一句话总结

M3 是"**稀疏化**"的胜利：MSA 让 428B 的模型跑出 23B 的速度。2026 年的开源模型，从"参数竞赛"转向"效率竞赛"——谁的架构更稀疏，谁的部署更便宜，谁就有生态。MiniMax 这一步，走在了前面。
