> Gemini 3 Pro 发布于 2025 年 11 月 18 日，多项基准跃升。Google 一直强调它是"原生多模态"（native multimodal）——这篇讲讲"原生"和"拼接"到底差在哪。

## 拼接式多模态（旧路线）

```
图像 → ViT 编码器 → 投影层 → 文本 token 空间 → LLM
音频 → Whisper 编码器 → 投影层 → 文本 token 空间 → LLM
```

每个模态有个**独立编码器**，再投影到文本空间。问题：

1. **信息损耗**：图像的细节在"翻译"成文本 token 时丢了。投影层是瓶颈。
2. **对齐困难**："这张图里的猫"和"猫"这个词，模型要学它们是一个东西——需要大量配对数据硬对齐。
3. **新模态=新工程**：加视频？再训一个编码器，再调投影层。

2024 年之前的所有多模态模型（包括 GPT-4o 的早期版本）都是这个路线。

## 原生多模态（Gemini 路线）

```
所有模态 → 同一个 Transformer → 统一 token 流
```

没有独立编码器，没有投影层。图像 patch、音频帧、文本 token，**从第一层就在一起训练**。

关键差异：

- **联合表征**："猫"的图像 patch 和"猫"这个词，在同一个向量空间里**自然对齐**——因为它们总是一起出现，一起被预测。
- **跨模态推理**："听这段音频，指出图里发出声音的东西"——拼接式要做两次翻译，原生式直接注意力。
- **扩展性**：加新模态=加新 token 类型，不用重构架构。

## 代价

原生多模态有两个地狱：

1. **数据**：需要海量"多模态交织"数据（图文混排、视频配字幕）。Google 有 YouTube，这是护城河。
2. **训练**：不同模态的 loss 尺度差 10 倍，梯度打架。调参是艺术。

## 为什么 2025 年底成了分水岭

Gemini 3 证明原生多模态在基准上全面领先后，行业开始转向：

- OpenAI 的 GPT-4o 本来就是原生路线（只是没明说）。
- Anthropic 的 Claude 还是文本优先，多模态靠后接——2026 年能不能跟上，看下一代。

## 一句话总结

"原生" vs "拼接"，本质是"一起长大" vs "后天翻译"。Gemini 3 证明，一起长大的孩子更聪明——但前提是你要有养大它的粮食（数据）和耐心（算力）。
